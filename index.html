1. ENREGISTREMENT & LECTURE
Cliquez sur R pour démarrer l'enregistrement, puis à nouveau sur R pour terminer.
Appuyez sur P pour faire une Pause, et P pour Reprendre.
Appuyez sur L pour lancer la Lecture d'un enregistrement.
2. IMPORTER DES SONS
Vous avez déjà des fichiers (musique, bruitages) ?
Cliquez sur + IMPORTER sous le nom d'une piste.
3. SÉLECTION MULTIPLE
Choisissez l'outil SÉLECTION (V) en haut.
Faites glisser votre souris dans le vide pour attraper plusieurs clips d'un coup (Lasso).
Astuce : Maintenez Maj pour en ajouter d'autres.
4. LE MONTAGE (COUPER)
Prenez l'outil CISEAUX (C) et cliquez sur un son pour le couper.
Vous pouvez aussi utiliser la touche S pour couper la piste sélectionnée.
Maj + S coupe toutes les pistes d'un coup !
5. SUPPRESSION MAGIQUE
Sélectionnez un raté et appuyez sur D pour l'effacer.
Encore plus fort : MAJ + D effacera le son et reculera automatiquement le reste pour boucher le trou !
